Git e GitHub

Git é um programa de computador instalado no seu computador para guardar o histórico e as versões do seu código.

  • Controle de versão: Registra cada mudança feita nos arquivos do projeto.
  • Uso local: Roda direto na sua máquina, sem precisar de internet para salvar as versões.
  • Segurança: Permite voltar para uma versão antiga se algo der errado no programa.

GitHub é um site na nuvem que armazena esses códigos e ajuda pessoas a trabalharem juntas no mesmo projeto.

  • Hospedagem na nuvem: Guarda cópias dos seus projetos salvos pelo Git.
  • Trabalho em equipe: Facilita a troca de arquivos entre vários programadores.
  • Portfólio: Mostra seus trabalhos públicos para outras pessoas e empresas verem.
